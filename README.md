# 🍸 O Fluxo Não Para - QG das Batidas
Catálogo Digital de Bebidas, Gestão Operacional e CRM em Taboão da Serra[span_1](start_span)[span_1](end_span).

## 🚀 Sobre o Projeto
Sistema operacional unificado desenvolvido para o gerenciamento de pedidos, cardápio digital com 30 batidas artesanais exclusivas, controle de estoque, fechamento de caixa com registro de sangrias e automação de campanhas via WhatsApp.

## 🛠️ Tecnologias Utilizadas
- **Python** (Lógica e Core)
- **Streamlit** (Interface Web Interativa)
- **Pandas** (Processamento de Dados e Tabelas)
